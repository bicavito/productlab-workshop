# data/

This folder contains the JSON datasets the app reads at runtime.

During the workshop, this folder is populated by Prompt 03:

```
prompts/03_data_model.md → data/[entity-name].json
```

The AI generates a realistic dataset based on your Feature Brief and data model.
The file it creates is the single source of truth your app loads via `fetch()`.

---

## File naming

The generated file is named after your primary entity, lowercase.

Examples:
- `data/candidates.json` (TalentFlow demo)
- `data/deals.json`
- `data/tickets.json`

---

## File format

```json
{
  "metadata": {
    "kpis": { ... },
    "filters": { ... },
    "thresholds": { ... }
  },
  "items": [
    { "field": "value", ... },
    ...
  ]
}
```

Do not edit this file manually. Re-run Prompt 03 if the data needs to change.
